# Security Policy

## Supported Versions

Security updates apply to the latest release version published on `main` and PyPI (`wide-sdk`).

## Reporting a Vulnerability

If you discover a security vulnerability in Wide SDK (such as command execution bypass, workspace path escape, credential leakage, or remote bundle checksum bypass):

1. Open a private GitHub Security Advisory at https://github.com/sl4de0day/wide-sdk/security/advisories/new.
2. Provide reproduction steps, affected SDK modules, and a minimal proof of concept.
3. Wait for a patched release before public disclosure.
